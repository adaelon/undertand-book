# ADR-0069 User-selected desktop library root
Status: Accepted, 2026-07-11.

**决策**:用户选择的书库根目录持久化到本地应用设置,验证成功后立即切换扫描与新建位置。

**否决**:
- Windows 注册表:安装器所有权与应用运行时设置混在一起。
- 自动迁移或复制旧书库:改变用户数据且可能产生双份 truth。
- 重启后生效:增加不可见状态且没有技术必要。

**命门**:选中 `.understand-book` 时直接复用,否则追加该目录名;已有目录原样使用,缺失则创建,任何校验或写入失败都保留旧设置。已保存路径在启动时不可用则禁止静默回落默认目录,Reader 进入待重新选择状态。

**何时回头**:需要同时挂载多个可写书库根目录,或跨设备同步应用设置。
