# ADR-0079 PDF selection banded reading order and conservative resynchronization

Status: Accepted, 2026-07-16.

### §1 页内阅读顺序

**决策**:页内先分水平带,再按带内栏序读取。

**否决**:
- 全页左栏后右栏:图表文字会插入跨栏正文。
- 固定页码或栏宽:只修当前样本。
- 仅扩大前视窗口:增加图表误匹配和计算量。

**命门**:分带与分栏只使用归一化 PDF 几何,无法判定时保持原始保守顺序。
**何时回头**:扫描件、竖排或旋转表格进入支持范围时。
**展开**:[PDF 选区映射稳定性切片方案](../切片方案-pdf选区映射稳定性.md)

### §2 失配重同步

**决策**:局部失配仅凭唯一强锚跨噪声重同步。

**否决**:
- 任意段落全局模糊搜索:重复正文会错绑 LID。
- 失配后永久停住 cursor:一次失败会污染整节。
- LLM 判断页框正确性:没有确定性验收锚。

**命门**:恢复候选必须单调、页距受限、锚点连续且唯一;否则 fail-closed 为 unmapped。
**何时回头**:真实语料证明唯一强锚仍产生错误映射时。
**展开**:[PDF 选区映射稳定性切片方案](../切片方案-pdf选区映射稳定性.md)

### §3 unresolved 交互

**决策**:工具条仅在选区解析完成后出现。

**否决**:
- unresolved 先显示 loading 工具条:造成选项闪现。
- 清除原生选区:破坏复制降级。
- 用整段 bbox 猜测动作范围:破坏精确引用。

**命门**:resolving/unresolved 都保留浏览器原生选区,只有 partial/resolved 生成动作 draft。
**何时回头**:解析延迟需要独立的非操作型进度提示时。
