# ADR-0082 Hybrid foundation semantic-unit alignment and degraded Reader

Status: Accepted, 2026-07-17.
Revises: ADR-0065 downstream-gate boundary and ADR-0071 reader-entry boundary.
Extends: ADR-0063 and ADR-0079.

### §1 来源文本与几何信任

**决策**:人工终裁只确认来源文本,不确认 PDF 几何。

**否决**:
- 人工决定直接认证 bbox:复核界面没有字符几何证据。
- 因几何不足否定来源文本:把两个独立信任问题重新耦合。

**命门**:`manual_override` 只能产生 `reviewed_hint`,后续必须确定性重验。
**展开**:[混合阅读基座 v2 修复方案](../修复方案-混合阅读基座语义单元对齐-v2.md)

### §2 语义单元对齐

**决策**:先定位证据绑定单元,再投影子 LID。

**否决**:
- 继续逐碎片首锚匹配:短正文和行内公式会制造级联失配。
- 合并 LID 适配算法:会破坏引用与既有分区不变量。

**命门**:Source alignment evidence 必须绑定最终 source/PDF/config 指纹。
**何时回头**:许可基准证明细粒度全局优化能在同等安全约束下稳定胜出时。
**展开**:[混合阅读基座 v2 修复方案](../修复方案-混合阅读基座语义单元对齐-v2.md)

### §3 子 LID 投影精度

**决策**:子 LID 独立分级,单元区域只作导航。

**否决**:
- 整单元共用 exact bbox:会把公式和短片段伪装成字符精确。
- 未映射子项继承相邻精度:会产生错误引用和标注。

**命门**:`region_exact` 不得进入字符引用、矫正版复制或持久标注。
**展开**:[混合阅读基座 v2 修复方案](../修复方案-混合阅读基座语义单元对齐-v2.md)

### §4 完整性与质量分层

**决策**:完整性决定成败,质量只决定分级。

**否决**:
- 覆盖率作为 hard gate:安全映射会因数量不足被误判失败。
- 取消全部质量目标:算法退化将失去可观测约束。

**命门**:完整性失败必须 fail-closed;`degraded` 仍保持逐项能力门禁。
**何时回头**:基准证明某个质量指标本身可确定性揭示错误绑定时。
**展开**:[混合阅读基座 v2 修复方案](../修复方案-混合阅读基座语义单元对齐-v2.md)

### §5 降级 Reader 能力

**决策**:Reader 按投影精度门禁操作并公开降级状态。

**否决**:
- 质量不足继续留在 Workbench:浪费已完成的来源复核成果。
- 静默降级:用户无法判断复制、引用和标注是否可靠。
- 模态确认后放开全部操作:确认不能提高映射精度。

**命门**:全局提示非阻塞,具体命令权限由当前选区精度决定。
**展开**:[混合阅读基座 v2 修复方案](../修复方案-混合阅读基座语义单元对齐-v2.md)

### §6 v2 迁移与原子替换

**决策**:新构建只写 v2,Reader 双读,整组原子替换。

**否决**:
- 就地覆写 v1 schema:旧书与旧 Reader 无法判别语义变化。
- 先删除旧产物再构建:失败会使已可信书不可读。

**命门**:候选产物全部验证成功前,官方 artifact 集保持字节不变。
**何时回头**:所有受支持书籍完成显式 v2 重建并结束兼容期时。
**展开**:[混合阅读基座 v2 修复方案](../修复方案-混合阅读基座语义单元对齐-v2.md)

### §7 版本化对齐基准

**决策**:版本化真值集校准阈值并承担发布判定。

**否决**:
- 只调当前论文到过线:阈值会过拟合单一版式。
- LLM 复核输出判定算法正确:缺少可重复的客观锚。
- 只看覆盖率:无法发现错页和重复绑定。

**命门**:错误页和重复绑定必须为零,质量策略版本不得随代码静默漂移。
**何时回头**:输入类别扩展到 OCR、竖排或扫描件时建立新基准版本。
**展开**:[混合阅读基座 v2 修复方案](../修复方案-混合阅读基座语义单元对齐-v2.md)

### §8 整版发布门

**决策**:算法、协议、迁移与 UI 同版通过整体验收。

**否决**:
- 先单独放开 degraded 路由:运行时尚不能约束危险操作。
- 等算法达到 full 才交付:继续阻塞安全可读的论文。

**命门**:内部切片可独立提交,但生产写入切换只能在整体验收后启用。
