# ADR-0086 Runtime-owned user-visible source references

Status: Accepted, 2026-07-20.
Extends: ADR-0015, ADR-0030 and ADR-0077.
Change type: 边界重构。

### §1 呈现权威与范围

**决策**:Runtime 强制把普通对话中的内部 LID 投影为用户可见来源引用。

**否决**:
- 只靠 Agent 自觉调用转换工具:遗漏调用会继续泄露 LID。
- 前端正则删除或替换:会误改版本号、公式与章节号。
- 强制每个书内主张都带来源:浪费 Agent 上下文且不增加呈现价值。

**命门**:来源可选;一旦呈现就必须合法。轨迹页是本次排除的显式诊断面。
**何时回头**:产品引入独立开发者模式或 LID 不再是内部证据身份时。
**展开**:[Agent 对话用户可见来源切片方案](../切片方案-Agent对话用户可见来源.md)。

### §2 本轮证据账本

**决策**:用户可见来源只能绑定当前回合已观察的结构化证据。

**否决**:
- 接受任意真实 LID:存在不代表 Agent 已读或该位置能支撑回答。
- 递归收集所有 `lid` 字段:视口和导航候选会被伪装成证据。
- 修改现有 `book.*` 返回契约:统一执行点已能旁路观察类型化结果。

**命门**:首版只接受用户验证选区、`book.query` citations、`book.synthesize` citations 与成功的 `book.text` 读取。
**何时回头**:新证据型工具提供等价结构闸时扩展提取器白名单。
**展开**:[Agent 对话用户可见来源切片方案](../切片方案-Agent对话用户可见来源.md)。

### §3 类型化回答编译

**决策**:Agent 放置受控来源标记,Runtime 校验后编译为类型化回答片段。

**否决**:
- 前端解析模型自由文本:无法证明句子与来源的绑定。
- 把 LID 传给普通 Web 组件但要求不显示:后续模板仍可误泄露。
- 静默清洗非法回答:可能改变原意或伪造来源。

**命门**:未知 ref 或原始 LID 泄露触发一次受限修复;再失败则关闭交付。
**何时回头**:所有 provider 都能原生交付等价结构化联合类型时。
**展开**:[Agent 对话用户可见来源切片方案](../切片方案-Agent对话用户可见来源.md)。

### §4 标签与句后来源按钮

**决策**:来源在相关句后显示为确定性命名的蓝色按钮。

**否决**:
- LLM 自由命名:跨回合不稳定且可与真实结构分叉。
- 回答末尾统一来源表:用户需反向猜测每条来源支撑哪句。
- 跨 LID 证据每节点一个按钮:把内部切分暴露为交互噪声。

**命门**:标签用本地化类型+原始章节标题;一个来源可绑定连续 LID 段,多来源合并为计数按钮。
**何时回头**:可用性测试证明句后按钮显著打断长文阅读时。
**展开**:[Agent 对话用户可见来源切片方案](../切片方案-Agent对话用户可见来源.md)。

### §5 来源弹窗

**决策**:来源按钮打开文本弹窗,不自动改变主阅读区。

**否决**:
- 首次点击直接跳主阅读区:破坏当前阅读与对话位置。
- 只显示几十字摘要:不足以核验证据语境。
- 把远处语义相关段拼成上下文:会混淆直接证据与召回线索。

**命门**:高亮精确证据,在最小共同结构边界内扩展连续上下文;次级命令才进入正文。
**何时回头**:精确 PDF 投影稳定支持弹窗内页面裁剪时。
**展开**:[Agent 对话用户可见来源切片方案](../切片方案-Agent对话用户可见来源.md)。

### §6 历史、失效与兼容

**决策**:历史只持久最小来源绑定,点击时实时复验并失效即关闭定位。

**否决**:
- 在历史中复制完整弹窗上下文:放大对话文件并制造第二原文。
- 失效后跳最近 LID:把系统猜测伪装成原来的来源。
- 自动改写旧对话:旧自由文本没有可靠的句子-来源绑定。

**命门**:保留标签/短预览快照;旧回答只转换明确 LID 格式,歧义数字保持原文。
**何时回头**:历史回合本身持久了可验证引用结构时扩大兼容投影。
