# ADR-0112 Pre-PHR reader body path rollback

Status: Accepted, 2026-08-20.
Revises: ADR-0105.
Change type: [边界重构].

### §1 Reader 正文实现基线

**决策**: Reader 正文渲染与装载链恢复到 `e64d5f0`，保留异步已读账本、画像与同期 build 等非正文能力。

**否决**:
- 整提交回退：会误删与正文无关且仍有效的能力。
- 保留未提交原生正文流：会继续携带本轮已判失败的耦合实验。
- 改写已发布历史：当前分支已有后继提交且工作区含独立改动。

**命门**: 生产正文路径及其测试以 `e64d5f0` 为逐文件基线，混合文件只反向应用正文 hunks。
**何时回头**: 新的端到端 profile 能隔离真实瓶颈，且候选实现通过正确性门与人工阅读验收。
