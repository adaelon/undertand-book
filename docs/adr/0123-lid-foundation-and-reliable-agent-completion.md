# ADR-0123 LID 底座与可靠 Agent 交付

状态：已接受，2026-09-08；LA1–LA6 已实现，定向结果见[实施与验收](../LA1-LA6实施与验收.md)；LA7–LA10 实现与实测交付完成，质量限制和裁决见[实施与验收](../LA7-LA10实施与验收.md)。
延续 ADR-0008、0086、0087、0113、0119。§2 补全 ADR-0104 §1/§3 与 ADR-0113 §1/§3/§8 中仅带读的显式动作入口；§3 细化 ADR-0086 §3 的受控标记编译；§4 收敛 ADR-0113 §6 的停滞处理。正式学习就绪仍遵循 ADR-0120。

## §1 坐标层与语义收益

**决策**：保留 LID 坐标层，图谱投入由增量收益决定。

**否决**：

- 因整套 Agent 失败移除 LID：混淆原文寻址与读时策略，破坏已有引用和记忆锚点。
- 因坐标层有用保留全部复杂度：位置真实不能证明语义正确或任务成功。

**命门**：LID、canonical source、Reader 与记忆锚点合同保持；本轮不改变正式学习所需的整份材料预构建门槛。
**何时回头**：同条件实验表明某项语义能力没有收益，或原文寻址需求本身改变时。
**展开**：[基线与切片](../切片方案-LID底座与Agent可靠交付.md)。

## §2 用户动作与执行权

**决策**：当前用户显式请求按具体阅读动作授权。

**否决**：

- 只把带读识别为写入意图：普通跳转、笔记和高亮无法使用已有能力。
- 模型声明写入或一次意图开放全部写工具：模型提议不能扩大用户请求。
- 用通用自然语言分类器或固定教学流程包办任务：额外决策层不解决既有动作合同。

**命门**：补全既有高精度动作入口，分别表达导航、笔记、高亮；否定按动作生效。Runtime 从当前用户请求确认范围，模型选择目标并调用，宿主权限及执行检查继续生效；发现本身不执行动作。
**何时回头**：真实开放表达无法可靠确认操作范围时，使用现有确认交互，不累加评测题专用短语。
**展开**：[LA1–LA2](../切片方案-LID底座与Agent可靠交付.md#la1-显式导航入口)。

## §3 来源交付责任

**决策**：Runtime 编译已选来源，Agent 判断语义支持。

**否决**：

- 为答案自动附上所有已读来源：无法证明模型选择了哪条证据支持哪句话。
- 放宽正文观察要求：真实 LID 和图谱摘要不是已读原文。
- 对可确定的标记格式错误反复调用模型：增加成本且可能改写正确结论。

**命门**：只规范化本轮已绑定、由模型在明确引用位置选中的来源标记；未知或歧义仍走现有一次修复。普通无来源回答继续合法，本评测的引用要求不升级为所有产品回答的强制规则。
**何时回头**：真实失败证明可接受语法存在歧义时，收窄语法并保留失败，不猜测绑定。
**展开**：[LA3](../切片方案-LID底座与Agent可靠交付.md#la3-来源标记交付)。

## §4 恢复与收敛

**决策**：合法恢复有界放行，终止后不再循环。

**否决**：

- 停滞后拦截一切工具但继续采样：既阻断恢复又持续耗费模型请求。
- 放开猜测 LID 或提高循环上限：把错误路径延长而非恢复。
- 接受禁用工具后的调用输出：将协议失败伪装为完成。

**命门**：定位账本与正文证据账本分离；仅真实新增定位、证据、能力或动作解除停滞。耗尽合法恢复机会后进入一次无工具终答，来源修复仍最多一次；错误和未完成不改判成功。
**何时回头**：有效长任务无法映射到既有阶段进展时，另行评审该类任务，而非放宽普通问答循环。
**展开**：[LA4–LA6](../切片方案-LID底座与Agent可靠交付.md#la4-合法定位与回读恢复)。

## §5 收益验证

**决策**：先修复完整链路，再做同环同预算消融。

**否决**：

- 用单轮 Chunk 与完整 Agent 的差异归因图谱：提示、工具与循环预算同时变化。
- 只保留成功样本或用单题替换基线：无法衡量真实任务质量和成本。
- 用节点、边或工具调用数量代替收益：规模不等于阅读效果。

**命门**：完整产品回归与受限工具消融分开；后者固定 Agent、模型、预算、题目和判分，只改变文本、结构邻接、语义图的访问能力，检查隐藏语义通道。成本使用实际 Provider 用量并分列预构建。
**何时回头**：同条件结果与独立题集不能复现增益时，收缩对应默认使用范围；正式学习资产变更仍须修订 ADR-0120。
**展开**：[LA7–LA10](../切片方案-LID底座与Agent可靠交付.md#la7-完整产品回归与成本分账)。
