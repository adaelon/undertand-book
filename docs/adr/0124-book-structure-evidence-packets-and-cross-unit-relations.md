# ADR-0124 BookStructure 资料包与跨章节关系

状态：已接受（2026-09-12，用户确认机制设计并要求实现）。

### §1 证据用途

**决策**：资料包统一派生模型与校验引用范围。

**否决**：
- 全书 LID 白名单：位置存在不能证明任务收到过正文。
- 独立维护模型与 writer 清单：造成资料可见而引用不合法。

**命门**：结构单元身份、正文证据、依赖目标分开；章节号和图谱节点 ID 不自动成为正文证据。

### §2 章节与全书分工

**决策**：本章摘要用本章证据，跨章关系在汇总形成。

**否决**：
- 禁止跨章关系：破坏 throughlines 和阅读依赖。
- 共享概念的所有邻边进入本章：把其他章节内容归属到本章。

**命门**：章节图谱投影保留本章有锚点的两端，裁剪共享节点的外章 occurrences；长程关系在汇总消费，两端资料一起交付。章节卡片不在看不到另一章资料时生成跨章依赖。汇总可从带出处的章节卡片推断联系，Pass2 仍是可选增强。

### §3 分片与验证

**决策**：关系分片保留证据，按引用用途验证。

**否决**：
- 只交付裸图谱边：模型只能从 ID 猜内容和出处。
- 只检查编号存在：不能证明资料已交付或关系两端有依据。

**命门**：图谱辅助分片携带对应摘录和节点锚点；汇总分片为跨界关系补齐上下文章节卡片及可用摘录，并计入现有预算。摘要按所属单元校验；依赖目标必须是已交付单元；主题线引用须覆盖其声明的各单元。机械校验验证来源覆盖，语义判断仍由模型完成。

### §4 发布与恢复

**决策**：通过新生成策略重建受影响的结构任务。

**否决**：
- 原样重试耗尽任务：不会修正输入契约。
- 修改已接受收据或手工替换引用：掩盖真实失败。

**命门**：复用现有 policy generation 与输入依赖失效机制；错误指出引用用途与字段，资料缺失在路由阶段处理。保留已完成的上游产物；不承诺输入改变的旧结构结果仍可复用。
