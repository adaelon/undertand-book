# ADR-0125 候选校验反馈与有界重试

状态：已接受（2026-09-12，用户确认根因并要求实现、重建插件）。

## §1 候选错误分类

**决策**：可定位的候选格式错误允许原策略纠正。

**否决**：
- 所有 schema 失败都要求新策略：把模型填错字段等同于契约错误。
- 扩大合法枚举接受错误输出：改变领域定义，掩盖生成错误。

**命门**：仅 `artifact_writer` 阶段、`schema_invalid` 且包含字段位置和期望格式的诊断进入纠错；证据不足、无结构诊断和策略契约变更保留原恢复要求。

## §2 执行器反馈

**决策**：下一次生成携带同范围的最近校验反馈。

**否决**：
- 原输入盲重试：无法利用已经确定的字段错误。
- 主任务读取候选并修补：破坏语义执行器的职责边界。

**命门**：代码从持久尝试读取反馈，只在专用执行器 `GENERATE.retry_feedback` 交付有界字段位置与期望格式；保持语义提示、输入和产物策略身份。反馈随生成响应冻结，重放一致；新输入/策略不得继承旧范围诊断。

## §3 耗尽恢复

**决策**：用户授权开启新的有限候选纠错窗口。

**否决**：
- 无限自动重试：重复错误无上限消耗。
- 清零计数或覆盖失败收据：丢失失败与授权历史。

**命门**：自动尝试仍最多三次；耗尽后每次用户确认只追加一次纠错机会，复用现有终态绑定恢复收据。旧请求的恢复建议不作为终态身份，仍校验其输入范围、失败收据和诊断绑定。`retry_current` 不能绕过 writer。
