# ADR-0129 BookStructure 追加组装与关系增量

状态：A1–A5 已实现（2026-09-14）；A5 复用与恢复验收见 [记录](../performance/understand-book-a5-release.md)。A6 真实模型验收待实施，Mastering Rust 的一份旧局部成果缺少七个 core 单元，须先定点修复。承接 ADR-0044、0124，替换全书拼接结果的递归整表汇总；单元提取仍沿用现有流程。

## §1 产物组装

**决策**：程序累计局部结构，模型只输出局部变化。

**否决**：
- 每层重写三个完整清单：输入随覆盖范围增长，形成大量单输入汇总。
- 把累计全表与新内容一起交给模型：append 仍会退化为全量重写。

**命门**：spine、key_stops、局部 throughlines 来自已接受的局部拼接成果，按来源身份确定性组装；重复应用不重复追加，完成顺序不影响产物。最终三清单由程序物化。
**展开**：[追加与关系增量切片方案](../切片方案-BookStructure追加组装与关系增量.md)。

## §2 跨片段语义

**决策**：相关条目定向整合主题与阅读依赖。

**否决**：
- 只拼接数组就称为全书理解：跨片段主题和依赖可能缺失。
- 同名即合并主题：名称相近不证明语义相同。
- 增量反复触发全书扫描：重新制造无终点的模型循环。

**命门**：代码从固定局部成果组织有限的相关条目工作集；模型提交新主题、主题扩展/合并与依赖补充，附两端资料证据。条目选择计入进度，补充结果不递归派生新一轮全表整合。
**展开**：[A2–A3](../切片方案-BookStructure追加组装与关系增量.md)。

## §3 复用与发布

**决策**：复用有效局部成果，发布累计三清单。

**否决**：
- 为切换算法重做全书：浪费仍有效的提取与局部拼接结果。
- 把旧汇总各层一起追加：同一内容多次计入且来源不清。
- 未完成关系任务就宣告完成：悄悄降低已确认构建范围。

**命门**：沿用现有输入/语义策略身份、收据与原子发布；局部贡献和关系变化使用确定来源，旧汇总仅保留历史。按任务完成、单元覆盖及引用一致性关闭，最终 sidecar 保持 spine/throughlines/key_stops 契约。
**何时回头**：相关条目召回遗漏实际跨章主线时，改善召回和证据交付，不恢复递归整表重写。
**展开**：[A4–A6](../切片方案-BookStructure追加组装与关系增量.md)。
