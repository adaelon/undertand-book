## §1 内容表达范围

**决策**：富呈现覆盖普通回答、教具与持续内容。

**否决**：
- 仅增加教学模拟器：遗漏普通回答的重点组织、比较和图文表达。
- 只调整 Markdown 样式：无法表达按当前问题生成的布局与行为。

**命门**：是否使用富呈现由当前任务决定；普通回答可直接使用，正式教学仍遵循 [ADR-0120](0120-whole-source-prebuild-gate-for-formal-learning.md) 的就绪要求。
**何时回头**：真实使用证明某类内容需要独立生命周期或产品入口时。
**展开**：[产品行为与验收场景](../切片方案-Agent富呈现与读时内容制作.md#1-产品行为与验收场景)。

## §2 现场制作能力

**决策**：首版支持现场编写、预览和修改内容。

**否决**：
- 只能组合预置组件：新问题的表达方式被组件集合限制。
- 只使用提前制作的教具：无法满足读者当场提出的内容与交互修改。
- 生成代码即宣告完成：缺少实际运行、观察和修正过程。

**命门**：制作能力接入现有 Resident 运行；关键交互须实际执行并返回反馈，制作成本与取消沿用运行治理。预览宿主的跨平台可行性由 RP1 先行验证。
**何时回头**：实测制作任务需要独立执行者时，再决定执行者形态。
**展开**：[制作与交付流程](../切片方案-Agent富呈现与读时内容制作.md#4-制作与交付流程)。

## §3 呈现与宿主分工

**决策**：内容自由生成，宿主拥有公共操作语义。

**否决**：
- 生成内容直接改写应用 DOM 与状态：来源、阅读动作和历史失去共同入口。
- 每次回答自行定义一套视觉规范：阅读层级、控件行为和主题表现不一致。

**命门**：应用提供共同样式与独立运行区域；来源、Reader 动作及正式教学提交经宿主既有权威处理。自定义视觉与局部计算可以扩展，来源身份、判题标准及学习状态不会由页面自行授予。
**何时回头**：真实内容需要新增宿主操作时，以明确输入和真实结果扩展接口。
**展开**：[所有权与接入边界](../切片方案-Agent富呈现与读时内容制作.md#2-所有权与接入边界)。

## §4 内容与交互的延续

**决策**：内容版本与实际交互保持可回读关联。

**否决**：
- 后续对话只保留一张截图或自由文本概括：无法可靠修改内容或解释当前参数。
- 修改覆盖历史版本：无法还原用户回答时实际看到的条件。

**命门**：普通回答内嵌与展开视图引用同一内容版本；修改创建新修订，历史保留原引用。当前参数、步骤及明确提交绑定具体版本；正式教学另记录实际呈现与帮助条件。
**何时回头**：产品引入跨用户共同编辑时，另定共享与冲突语义。
**展开**：[内容与现场合同](../切片方案-Agent富呈现与读时内容制作.md#3-内容与现场合同)。
