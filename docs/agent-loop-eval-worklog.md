- 透明转发测试：发现请求体被改写、漏计请求或缺失 usage 被当成零；出现则修记录器，不发布成本。
- 首题真模：发现实际未进入工具循环、来源无法解析或独立记忆未生效；出现则修接入。
- 判分测试：发现伪造引文、错误事实、未执行动作获得成功；出现则修判分，不放宽金标准。
- 全量实验：检验真实任务能力；保留未完成和错误，不筛掉不利结果。
