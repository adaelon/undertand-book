## 测量边界

语料由用户指定为 `.understand-book/quantification-essence`（《你认为量化的本质是什么？》）。只读已有完整基座，不触发预构建。仅公开自编题目、事实槽判据和局部定位锚，不分发原书全文。检索器只接收问题；参考答案和证据锚不进入模型。比较的是检索策略，共用模型、提示、原文预算，不冒充完整多轮 Agent 对照。

答案以有语义的封闭事实槽表达，按预先给定的可接受值和支持原文联合判定。自由解释质量不混入自动分数。来源定位检查真实 reader.goto 与原文回读；持久记忆检查独立临时目录中的真实服务进程退出/重启，不将数据库持久化冒充模型自动记忆。

## 验证目的

- 单元测试发现预算越界、参考答案泄漏、引用伪造、错误答案被计分及聚合分母错误；出现则修评测代码。
- 真实服务测试发现 REST 参数/返回值不兼容、跳转或持久化失败；保留失败并修测试接入或报告产品问题。
- 两系统全量实测发现真实检索与回答差距；保留初始结果，改动检索策略须另立运行版本。
- README 启动和截图检查发现缺少资源或文档命令不可运行；修交付路径。

## §1 测量对象

**决策**:固定题集比较检索策略，记忆单列。

**否决**:

- 将共享 Reader 记忆计入图谱收益：两组共享实现，归因不成立。
- 以开放回答的主观评分作为唯一验收：当前事实槽和原文锚可以确定性核对。

**命门**:参考答案不进入检索器和模型；引用锚代理存在替代表述漏判，必须与语义正确性区分。
**何时回头**:加入开放讲解或自主多轮 Agent 时，新增独立任务与判据。
**展开**:[方法](../evals/semantic/README.md)、[失败复核](../evals/semantic/findings.md)。

## §2 回答器与公开产物

**决策**:两组共用证据编号，原始记录留本地。

**否决**:

- 模型逐字抄写所有引文：首轮出现公式转义、改写和输出截断失败。
- 将完整运行记录直接入库：含用户原书片段，公开表不需要这些全文内容。

**命门**:v1/v2 分开保留；v2 同时提高输出上限，不能只归因于引用协议。书库不回写，测试使用临时独立记忆。
