## 0. 目标与对齐

**FrozenIntent（LA0 立项时）**：保留 LID 原文坐标与完整 Agent 决策循环，修复普通阅读动作、来源交付、合法恢复和停止行为，再测量复杂度的实际收益。LA0 交付 ADR 与实施方案，验收为每个已确认缺口都有源码入口、独立切片、确定性判据和真实场景复验。后续实施进度见本文顶部与独立验收报告。

**TermMap**：下列均沿用 [CONTEXT](../CONTEXT.md) 的既有定义：LID / canonical source（位置与原文）；本轮定位来源账本 / 本轮证据账本（可读位置与已读证据分离）；用户可见来源引用（Runtime 绑定与展示）；TaskNeed / 工具暴露计划（模型提议、Runtime 权限）；ProgressPhase / 最终收敛采样（实际进展与有界终答）；Reader / 阅读记忆（已有操作与持久化所有权）。无新增领域对象。

**RiskReceipt**：用户在完整基线及“保留 LID、先修闭环、同条件验证图谱”的分析后要求落 ADR 和切片方案。已知取舍：减少无效循环可能更早返回未完成；规范化引用必须避免猜测句子与证据关系；图谱消融可能没有收益。以上结果均保留，不通过放宽判分消除。

**ChangeType**：既有行为合同的技术补全。Agent 的语义取舍、Runtime 的执行权和证据来源定义保持；实施前若发现必须改变这些领域边界，单独修订决策。

本方案延续 [ADR-0119](adr/0119-agent-native-learning-environment-and-teaching-agency.md) 的 Agent 教学选择权及 [ADR-0120](adr/0120-whole-source-prebuild-gate-for-formal-learning.md) 的正式学习门槛。“图谱按需使用”指读时策略及实验访问范围，不表示撤销整份材料预构建。

## 2. 行为合同

**动作**：

```text
当前用户原文 → 确认本轮具体动作范围
模型提出能力需求 ∩ 用户动作范围 ∩ 宿主权限 → 可见操作
模型选择目标并调用 → 既有参数/Reader 检查 → 实际 effect 与回执
```

沿用 `classify_turn_intent / seed_turn_tool_activations / stamp_task_need` 入口。将“是否有任意 Reader 写意图”的单一判断补全为可区分导航、笔记、高亮的操作范围；带读仍只激活自己的导航能力。开放语义仍由 Agent 处理，高精度入口只确认明确动作，不覆盖所有自然语言意图。

`只解释这段` 不产生写入；`不要跳转，只保存笔记` 仅允许笔记；用户问题或书中引文提到“高亮”不等于请求高亮。定位目标歧义不由 Runtime 猜测。发现与预激活不提前改变视口或记忆。

**来源**：

```text
合法 locator → 成功回读 → 本轮 evidence → Agent 选择 source.present
→ Agent 在回答中选择具体 ref → Runtime 编译 → answer_view → 真实来源解析
```

`[[source:<ref>]]` 为现有标准语法。规范化仅面向真实失败中可无歧义识别的、句后引用位置上的已绑定 ref 格式；普通代码、引用原句及讨论标记本身的文本不进行替换。没有 ref 选择就不自动附证据；只有位置元数据也不能授权来源。无歧义格式走程序，未知/歧义走既有一次模型修复，失败保留。

**恢复与结束**：

```text
本次调用被拒绝
  ├─ 仍有合法恢复动作 → Agent 获得有界恢复机会 → 实际进展则继续
  └─ 恢复无新进展 / 没有合法下一步 → tools-disabled finalization
       → 答案编译（必要时仅一次来源修复）→ 返回完成或未完成并停止
```

恢复机会不允许执行猜测位置，也不因换参数清零停滞。恢复预算属于既有总循环预算；无工具终答不能重新开启工具循环。协议错误保留结构化原因，用户结果仍如实标为失败/未完成。

## 3. 切片依赖与边界

```text
LA0 文档
 → LA1 导航 → LA2 笔记/高亮 → LA3 来源交付
 → LA4 合法恢复 → LA5 停滞收敛 → LA6 最终协议
 → LA7 完整回归与成本分账
 → LA8 同条件消融入口 → LA9 收益裁决
 → LA10 持续阅读体验验收
```

串行推进，共享 `orchestrator.rs` 的切片不可同时实施。每刀先复现红测，再改最小路径；真实场景复验写入新目录，不能和其他版本拼成一轮成绩。

范围限于现有 Reader、Runtime 与评测入口。LID 编码、原书、图谱构建器、教学领域设计、默认模型与持久格式不在本轮改动范围。实验访问控制仅用于显式实验，不新增产品功能开关、兼容层或另一套 Agent。本轮按用户要求刷新全局 `SESSION_CHECKPOINT.md`；Linux 与预构建前序状态保留接手指针。

## LA1 显式导航入口

**输入 → 输出**：普通“找到并跳转”请求 → 本轮导航操作范围、可调用工具与真实阅读器位置。
**触达**：[tool_exposure.rs](../crates/runtime/src/tool_exposure.rs) 的 `classify_turn_intent / seed_turn_tool_activations / stamp_task_need`；[orchestrator.rs](../crates/runtime/src/orchestrator.rs) 的权限传递和 Reader dispatch；Registry 继续单源定义能力。
**做**：补全普通明确导航的入口；与带读、普通解释分别测试；范围在发现和执行处一致，导航不能顺带获得笔记/高亮权限。
**边界**：本刀不改变笔记、高亮或教学策略。
**红测/验收**：未包含“带我读”的明确跳转能够发现并成功调用目标工具；只读、否定、无宿主权限无 effect；发现前后视口不变，只有合法调用改变视口。
**验证**：扩展现有 `tool_exposure`、`task_need`、Reader dispatch 定向测试；真模运行 `source-01` 至 `source-04`，以成功回执和目标视口判定。若仍不跳转，按“入口 / 模型未调用 / 执行失败”分层处理，不在评测器中补动作。

## LA2 显式笔记与高亮入口

**输入 → 输出**：保存笔记/高亮的明确请求 → 正确类型、内容和原文锚点的持久记录。
**触达**：LA1 的意图与暴露路径、`ReaderNote / ReaderHighlight` dispatch、[memory Anchor](../crates/memory/src/lib.rs) 与 [agent-run](../evals/semantic/agent-run.mjs) 的只读验收路径。
**做**：分别传播笔记/高亮意图；按动作处理否定和混合请求；保存结果必须来自生产持久记录。
**边界**：不改存储 schema、迁移机制或默认开放全部 ReaderWrite。
**红测/验收**：`不要跳转，只保存这条笔记` 只有笔记 effect；解释“如何做笔记”不写入；重启前记录的 `type / anchor.lid / content` 正确。重启后新聊天自行恢复，不含原答案提示。
**验证**：补动作正反例与实际 MemoryStore 集成测试；运行四道 `restart-*`。准备失败、持久化失败、Agent 未恢复分列；只有准备通过后的丢失才进入持久化修复。

## LA3 来源标记交付

**输入 → 输出**：已读证据、已生成 ref 与失败答案格式 → 有正确句后绑定、可解析的 `answer_view`。
**触达**：`compile_agent_answer / parse_source_marker / deliver_agent_answer`、[agent_prompt.rs](../crates/runtime/src/agent_prompt.rs) 的来源 policy、现有 `/agent/source.resolve`。
**做**：先从六道“内容正确但无引用”记录区分：已有绑定但格式错误、未创建绑定、语义支持不足。只有第一类进入确定性标记规范化；第二类修模型可见的来源使用合同；第三类保持失败归类。
**边界**：本刀不修检索，不把已读全集附到回答，不改每条产品回答都必须引用的政策。
**红测/验收**：已绑定且无歧义的引用格式零修复模型调用即可编译；未知 ref、未读原文、无引用意图、代码内标记不被自动绑定；保留普通列表、版本号与原文数字回归。

## LA4 合法定位与回读恢复

**输入 → 输出**：`LID_PROVENANCE_REQUIRED / LID_NOT_FOUND` 后的真实定位状态 → 一条仍遵守账本合同的可执行恢复路径。
**触达**：`TurnLocatorLedger / TurnEvidencePlanLedger / ProgressPhaseGuard`、`attach_lid_recovery_requirement` 与 dispatch 前检查。
**做**：复现“错误读取后拿到合法 locator，却因全局停滞不能回读”的序列；按当前真实条件保留一轮定位/回读恢复机会，同样计入总预算。错误回执指向所缺能力或已经合法的读取方式，不再暴露无效重试建议。
**边界**：不登记猜测的 LID，不把 context/搜索预览当完整正文，不为错误接口增加旁路读取。
**红测/验收**：新合法 locator 可解除对应读取阻断；原文成功读取才进入 evidence；重复猜测、同批次尚未完成的 locator、换参数但无状态变化均不算进展。恢复无实际增量交由 LA5 收敛。
**验证**：现有 `book_text_provenance / locator_ledger / lid_not_found_recovery / evidence_plan_gate` 测试及新增跨阶段序列；真模复验 `concept-02,cross-01,cross-02`。只检查可执行恢复，不预写模型的全部工具顺序。

## LA5 停滞后的及时收敛

**输入 → 输出**：已用尽合法恢复机会的停滞阶段 → 一次终答机会并停止。
**触达**：`ProgressPhaseGuard / ToolCallProgressGuard / run_with_turn_resources_and_checkpoint_sink`。
**做**：把“所有工具都将被拒绝”的状态接入外层停止分支；保留现有连续无进展阈值及最后无工具采样；不继续逐轮给不同工具返回同一个拒绝。
**边界**：不提高 12 轮默认上限，不新增全局重试框架，不通过删掉有效证据腾预算。
**红测/验收**：终止条件成立后，普通有工具采样次数为零；至多一次终答、至多一次既有来源修复；终止前真实新增证据仍可继续；未完成与拒绝不混为成功。
**验证**：扩展 `agent_progress_phase` 和 `finalization_sampling` 请求计数测试；复验 concept-02，直接比较终止条件之后的请求数和实际 Token。若停止过早拦截合法工作，回到 LA4 修恢复条件而非增大阈值。

## LA6 无工具终答协议

**输入 → 输出**：refusal-03 的最终协议事故 → 可验证的无工具请求与一致的失败/未完成交付。
**触达**：orchestrator 的 `FINALIZATION_INSTRUCTIONS / looks_like_disabled_tool_invocation`、[runtime lib](../crates/runtime/src/lib.rs) 的 `NativeAdapter / ReActAdapter`、[server](../crates/server/src/lib.rs) 的 Agent 错误投影。
**做**：核对请求中的空工具面、`ToolChoice::None` 与 Provider 序列化是否一致；若请求正确而模型仍产出调用，保留协议错误，不执行工具。沿用现有用户失败结果，防止错误令该任务失去可观察的最终状态。
**边界**：本刀不接纳违规工具输出、不再次开环、不把协议失败改判为“证据不足拒绝”。不预设 Provider adapter 一定有 bug。

**验证**：既有 `finalization_sampling`、Adapter request serialization 和 Server 错误投影测试；真模复验四道拒绝题，独立列出正常拒绝、未完成、协议失败。

## LA8 同环消融入口

**输入 → 输出**：可靠的生产 Agent 与现有评测器 → 仅供实验的三个读时访问配置。
**触达**：评测启动入口、Runtime ToolRegistry/Book 读取注入点、[read-tools](../crates/read-tools/src/lib.rs) 的 context 投影；复用现有 Agent loop、证据账本与交付路径。

| 组 | 可用证据定位 | 保持相同 |
| --- | --- | --- |
| Text | LID 原文＋词法检索 | 原书、LID、Agent 控制、来源与判分 |
| Tree | Text＋确定性章节树、父子与邻接扩展 | 模型、基础提示、预算、记忆隔离 |
| Graph | Tree＋概念/语义关系定位与扩展 | 回读原文后才能作为正文证据 |

**隔离要求**：Text/Tree 不能通过 `book.query/synthesize/concept/structure`、默认环境、画像或私有构建资产间接读到预构建语义信息。首版三组共同关闭会内含语义检索/综合的高层工具；Tree 的结构只由 canonical 章节树投影，不使用含模型主线和关键停靠点的 BookStructure。Graph 增量通道明确记录。被剥离的入口不能经 `tool.search` 重新出现。
**边界**：实验配置显式传入、与生产默认隔离；不删除或改写原始图谱，不生成第二套 Agent。此实验是完整循环下的能力消融，不冒充完整默认产品成绩。
**红测/验收**：三组原文回读相同；仅在语义资产中放置测试标记，Text/Tree 的实际模型输入不可出现该标记；图可影响召回，不可绕过 evidence；直接与 discovery 两种入口均按同一访问配置执行。
**验证**：注入路径、请求投影和回读集成测试；先做一题三组接入检查，成本和成功均单列。

## LA9 同条件收益裁决

**输入 → 输出**：LA8 三组与固定题集 → 成对结果、具体收益场景及默认策略建议。
**实验规模**：先用原有 24 道共同问答，每组每题一次，共 72 个系统样本；八道动作题留在完整产品回归。开始前一次性冻结配置与运行顺序，所有失败保留。
**共同配置**：同一 `deepseek-v4-flash`、同一模型 profile、基础提示与判分版本；最多 12 轮、单任务 300 秒；累计实际 Provider Token 上限初定 120,000，全任务唯一正文暴露预算 12,000 UTF-16 字符。每次采样输出上限相同，具体值随当前 profile 写入运行清单；Tool schema 限额相同，实验开启后不逐题调参。
**预算语义**：正文重读继续计实际 Token，但唯一正文预算按 LID 与区间并集计量；语义摘要和工具元数据占总 Token。已发出的模型请求可能使累计用量超过上限，报告实际超出，并在下一次采样前停止；终答/来源修复使用共同预留，预算不够则如实未完成。任一请求缺失 usage，该样本成本记 N/A，不宣称满足累计用量上限。预算派生结构仅用于测量，不能绕过原文证据闸。
**裁决**：Tree 对 Text、Graph 对 Tree 分别比较成功题、证据、引用、P95 与 Token；列出哪些题因哪条新增路径改变结果。若更贵且没有新增任务成功，暂不扩大该能力的默认使用；若只在跨章节题有效，形成按需使用建议，不强制普通定位也走图。
**预构建**：单列本书可核实的构建用量、耗时、产物体积；缺失历史用量记未知，不为补表重建原书。只有读时成本确有下降时才计算 `额外构建成本 / 每次读时节省`；无正节省就没有成本回收点。
**验证**：使用与 LA7 相同的原始记录/公开报告分离方式和判分程序。正向结论先在新冻结的小题集上复核再进入 README 主张；本轮单次开发集结果不作统计显著性宣称。

## LA10 持续阅读体验验收

**输入 → 输出**：前述可靠动作与引用能力 → 读者真正能完成的连续阅读场景。
**场景**：选择原文并解释 → 打开来源弹窗核对 → 明确跳转 → 保存自己的笔记 → 关闭并重启 → 新聊天找回笔记与位置。补一组跨章节概念追踪，要求两端都能查看真实来源。
**触达**：现有 Reader、[RightRail](../packages/web/src/components/RightRail.vue)、[Web API](../packages/web/src/api.ts) 与评测入口；使用独立测试记忆。
**边界**：不引入新教学对象、掌握度模型或 TutorLoop；不将找到笔记等同于学会知识。
**验收**：前端真实点击能解析同一来源、执行成功后的界面状态与服务一致；重启后原文锚点和记录内容一致；新聊天自己获取持久内容。引用点击默认仅弹窗，不能未经请求跳主阅读区。
**验证**：生产服务与真实前端集成场景，加一次真实模型连续阅读回放；失效按“来源 / 动作 / 存储 / 新聊天 / UI”定位，不用演示截图代替行为证据。

## 5. 当前限制

这是一份实施方案，不是修复后成绩。单书开发集、同模型家族标注、开发机延迟及缺失历史构建成本仍限制结论；参考锚组也不穷尽所有等价证据。动作准备失败不等于存储丢失，引用编译通过不等于语义支持正确，消融的访问限制不代表日常产品默认工具面。新策略不得直接改写原报告或取消正式学习就绪门槛。
