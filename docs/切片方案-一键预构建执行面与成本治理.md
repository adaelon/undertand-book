## 1. 全局纪律

每个切片必须满足:

1. 只改变一个行为面;功能、迁移和生产切换分开。
2. 先写能复现当前缺陷的失败测试,再改实现。
3. v2 中间产物使用独立 namespace,不得覆盖 v1 运行样本。
4. 任何模型候选仍由专用 subagent 生成;sidecar 不直连模型。
5. 任何 `done` 都由 artifact 回读和 gate 得出,不信任 job/task 自述。
6. 每片完成后追加 `docs/代码链路.md`;结构真正改变时才更新 `docs/架构.md`。
7. 生产 `automatic_build_next.v1` 默认行为保持不变,直到 AP16 发布片。

全局禁止:

- 不在中间切片自动迁移或删除 Understanding Transformer 的既有 artifact。
- 不用 `--allow-partial`、空输出、模板 sidecar 或默认 reject-all 通过测试。
- 不用 LLM-as-judge 代替 schema/hash/evidence/goldset 判定。
- 不把估算 Token 填入精确 Token 字段。
- 不以提高并发掩盖 target、lease 或 artifact identity 错误。

## 2. 依赖图

```text
AP0 docs
  -> AP1 target identity
      -> AP2 per-task attempt store
          -> AP3 lease/claim/recovery
              -> AP4 mailbox submit/receipt
                  -> AP5 Codex artifact handoff
                  -> AP6 metrics + usage receipt
      -> AP7 policy-bound artifact identity
          -> AP8 prompt/schema single contract
          -> AP9 stage work-unit router framework
              -> AP10 metadata router
              -> AP11 lexicon router
              -> AP12 sidecar semantic units
          -> AP13 preflight budget + cost scheduler
              -> AP14 concurrent execution release gate
AP5 + AP6 + AP10 + AP11 + AP12 + AP14
  -> AP15 quality gates + legacy migration
      -> AP16 packaged release + real-paper replay
```

AP1-AP8 修复执行可信度。AP9-AP13 减少无价值工作。AP14 只在状态协议安全后打开并发。AP15-AP16 才处理旧运行和生产切换。

## 3. 协议版本与目录

开发期显式使用:

```text
automatic_build_protocol.v2
.build/automatic-build/v2/
semantic_task_artifact.v2
```

在 AP16 前:

- v1 CLI、v1 artifact 与现有 plugin skill 继续可用。
- v2 只通过测试或显式开发参数进入。
- 公共 `paper_metadata.json`、`paper_lexicon.json`、`discourse_index.json`、`formula_semantics.json` 不由半完成 v2 stage 发布。

## 5. 发布门禁汇总

所有条件合取:

1. Paper target round-trip 不再创建假 workspace。
2. Attempt/task 状态可并发、可恢复、幂等且不依赖共享 RMW ledger。
3. Root 正常路径不接收完整 candidate JSON。
4. Sidecar 未新增模型/provider 依赖。
5. Prompt/schema/quality/router 变化可确定性使 artifact stale。
6. Metadata、lexicon、discourse、formula 使用各自 work-unit router。
7. Stage 中途 quality profile 变化被阻断。
8. Token 缺失显示 unknown,estimate 不冒充 usage。
9. Legacy artifact 不被自动覆盖或错误升级。
10. 真书两次隔离构建 digest 稳定,完整性与选定质量 floor 全部通过。

任一条件失败,AP16 不得切默认协议。
