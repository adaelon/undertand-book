## 1 产品行为合同

### 1.1 工作区模式

| 模式 | 主体 | 导航与辅助区 | 进入/退出条件 |
| --- | --- | --- | --- |
| `single` | 正文、问答或被选中的辅助内容占主区域 | 窄屏顶部轻量导航；底部阅读/问答/笔记/更多；目录抽屉 | 空间不足、用户专注选择、长任务展开；退出后保留原选择 |
| `compare` | 正文＋Agent，独立滚动 | 目录按需打开；低高度只保留一条操作带 | 存在对照意图且双方最低空间都满足；不由横屏无条件触发 |
| `wide` | 既有桌面工作区 | 保留目录与辅助栏以及原有桌面操作 | 可用空间满足宽屏下限，且用户未要求专注 |
| `input-priority` | 当前编辑区域与必要上下文优先 | 暂时收敛次要导航；发送和引用摘要可达 | 已聚焦编辑且可用高度不足；不是一种永久保存的布局偏好 |

`input-priority` 是临时呈现覆盖，不覆盖用户的 `auto/focus/compare` 偏好。RP 展开、来源预览、目录抽屉属于覆盖层，不另建一套书籍或会话。

### 1.2 动作合同

| 动作 | 必须发生 | 不应发生 |
| --- | --- | --- |
| 打开问答 | 显示原会话及上次查看位置 | 自动弹键盘；无条件滚到最新消息 |
| 对选区提问 | 冻结有效 SelectionContext，再进入编辑；显示可清除引用 | 切区后重新读取已经丢失的 DOM Selection |
| 点击来源标签 | 先展示来源预览，不改变正文读位 | 仅打开预览就调用导航/保存新读位 |
| 在来源预览中打开原文 | 保存返回点，调用既有权威来源打开接口，显示实际目标 | 将 source resolve、source open、goto 各调用一遍造成重复副作用 |
| 返回刚才的回答 | 回到该消息/RP 及原交互现场；按返回点恢复原阅读位置 | 回到聊天末尾；重建 RP；重复发送问题 |
| 关闭目录、更多或预览 | 返回打开前的主区域与合理焦点 | 当成正式关闭 slot 或停止运行 |
| 旋转手机、工具栏伸缩 | 重算呈现并保持语义锚点 | 换书、重建聊天、提交 layout action 或写画像 |
| 在输入中收到 Agent 布局请求 | 记录并展示待呈现状态；安全时执行最新有效请求 | 抢输入法焦点；沉默丢弃请求；谎称目标已可见 |
| 后台返回或临时断网 | 核对原 turn 快照并续接观察 | 再次创建同一运行 |
| 打开历史 RP | 读取原版本及可用的已保存现场 | 将旧版静默升级成新的“手机版” |

### 1.3 首版保护等级

- **同一存活页面**：旋转、切区、开关键盘、开关浮层，以及暂时进入后台，保护草稿、冻结引用、读位、消息位置和 RP 现场。
- **刷新/系统回收/重新打开**：恢复后端已持久的书籍、会话、读位及 RP 现场。未发送草稿和未保存交互不承诺恢复；界面不能把“上次已保存”说成“刚才所有操作已保存”。
- **身份改变**：书籍、来源版本、会话或 RP revision 不匹配时使旧临时状态失效或明确降级；禁止静默套用。

首版不为了宣称“永不丢草稿”而默认把原文、选区和私人问题写入 localStorage。需要页面回收后的草稿恢复时单独设计。

## 2 最小技术合同

### 2.1 逻辑状态、交互状态、几何状态分离

下面是前端职责草图，不是新的后端 schema。正式共享类型继续从 Rust 生成，不手改 `src/generated/`。

```ts
// 拟新增于 workspace-layout.ts；具体字段在 MW1 测试中冻结。
type WorkspaceMode = "single" | "compare" | "wide";
type DisplayPreference = "auto" | "focus" | "compare";

type WorkspaceProjection = {
  mode: WorkspaceMode;
  foreground: string;          // 前端区域注册表标识，不冒充后端 slot
  visibleRegions: string[];
  inputPriority: boolean;
  navigation: "bottom" | "compact" | "desktop";
  deferredFocus: null | { target: string; logicalRevision: string };
};

// 只计算呈现；不读取 DOM、不发送请求、不更新持久状态。
resolveWorkspace(logicalState, viewport, interaction, preference): WorkspaceProjection;
```

MW0 必须产出“区域入口 → 既有组件 → 是否正式 slot → 使用哪个 API”的映射。RightRail 的 `agent/artifacts/profile/trace/formula/notes` 是当前本地标签，不能直接当成同名的后端 slot。对不支持的正式 slot 显示明确状态，不伪造组件已挂载。

用户显式改变正式 slot/preset 走原 `layoutApply`；几何摆放走纯投影。后端 revision 原有类型保持不变，本地去重键可转为字符串，不新增有精度损失的 `Number(bigint)` 转换。

### 2.2 布局决策顺序与初始参数

可用宽度指工作区实际内容盒宽度，安全区及内边距只扣一次。内容高度指扣除当前可见操作带之后的可用高度。逻辑布局分类以布局容器为主，不随用户双指缩放不断重排；视觉视口用于输入和浮层可见性。

初始参数只是工程起点，MW0/MW2 根据实测调参并记录；不得在文档中将它们表述为 iPhone 标准：

| 参数 | 初值 | 用途 |
| --- | --- | --- |
| 对照正文最低宽度 | 400 CSS px | 普通技术正文初始可读下限 |
| 对照 Agent 最低宽度 | 320 CSS px | 回答和输入区初始下限 |
| 对照间隔 | 12 CSS px | 推导对照最低可用宽度为 732px |
| 对照内容最低高度 | 200 CSS px | 低于此值退为单区/输入优先 |
| 宽屏内容最低高度 | 420 CSS px | 避免低矮手机仅因宽度大而套桌面布局 |
| 主要点击目标 | 44×44 CSS px | 项目交互目标；不是对所有内联链接的机械放大 |
| 输入字体 | 至少 16 CSS px | 初始可读性约束，是否出现浏览器自动缩放仍须实测 |
| 正文与代码字体 | 正文约 17px；代码约 14–15px | 可调设计初值，不通过整体缩小解决越界 |

宽屏最低宽度从实际已打开栏位的下限及间隔推导，不再增加一组到处复制的魔法断点。对照模式第一轮只要求正文＋Agent；笔记、画像等长任务先进入单主区域，后续需要并排时通过注册能力扩展。

决策顺序：

1. 检查有效尺寸、当前上下文身份和显式展开状态。隐藏/零尺寸不触发持久读位变化。
2. 用户要求专注时使用单区域；空间不够时也使用单区域，但保留原对照偏好。
3. 空间满足宽屏条件且没有强制专注时使用宽屏呈现。
4. 有对照意图，且正文、Agent 的实际最低宽高均满足时使用对照；否则单区域。
5. 编辑焦点与视觉可用高度共同决定是否覆盖为输入优先。不仅凭“高度减小”认定键盘弹出。
6. 在尺寸变化稳定后一次性应用最新投影并恢复锚点；恢复未结束又有新变化时废弃旧恢复，不排队重放所有中间布局。

“对照意图”来自用户显式选择或已进入问答对照任务，不是仅因历史聊天非空。用户回到连续阅读后，不应被新消息持续拉回问答。

### 2.4 滚动、覆盖层与焦点

应用工作区在 `reader` surface 内有确定高度。每个可见主区域只指定一个主要纵向滚动容器；代码/表格可以有局部横向滚动；RP 内部滚动是明确的内容边界。不能让文档根与 ReaderPane 同时承担正文纵向滚动。

使用 `100dvh` 时保留兼容回退；输入和浮层根据顶层视觉视口处理位置。不要把键盘估计高度、视觉视口缩小量与安全区重复扣减。记录 `offsetTop/offsetLeft/scale` 的使用场景；双指缩放不应触发内容整体反向缩放。[W2][W3][W4]

浮层由统一宿主管理；同一时刻只有最上层模态获得交互和焦点约束。背景不应被读屏或键盘误操作。关闭后恢复可见的触发入口，不能将焦点送到隐藏按钮。浏览器返回仅处理应用自己压入的历史项；不拦截系统侧滑手势，不吞掉真正的页面退出。几何变化不新增历史项。

展开 RP 先核对父层的 `transform/filter/contain/overflow` 对定位和裁剪的影响。优先稳定 DOM 与 CSS 摆放，不因方便而动态迁移 iframe。若无法避免重建，必须先获得可恢复现场；保存失败阻止破坏性切换。不能用 iframe 元素引用没变证明 browsing context 没重载，须检测 load 次数与内部现场。

### 2.5 连续性与返回点

返回点只作为前端暂存，默认有界栈（初值最多 16 项），不写学习记忆。至少关联：当前书/来源身份、会话、阅读表面、阅读锚点、消息或 RP 身份、原主区域、原显示偏好。书/来源或会话变化时清除不适用项。

正文优先复用已有 LID 锚点。对长段落，增加可选的段内 UTF-16 偏移；偏移只能来自规范正文映射，不含装饰性行号。恢复需要等待 DOM 和布局稳定，并通过代际编号阻止旧异步结果覆盖新位置。一次主动跳转或用户再次滚动应使旧恢复任务过期。

来源“预览”无导航副作用。“打开原文”由协调入口保存返回点后**恰好调用一次现有权威来源打开动作**；不在返回数据处理时再发重复 goto。返回原读位是用户显式导航，可以走既有定位/持久化路径；纯旋转恢复不当成新阅读意图。

消息返回锚点采用稳定 turn/message 身份及相对位置，不使用数组下标。未获服务器 turn 身份的本地待发送记录如需定位，可用临时 UI key，但不能把它发给服务端当权威 turn。

### 2.6 异步与隐私约束

所有延迟测量、选区解析、PDF 渲染、消息回调和现场恢复都绑定当前书/来源/会话代际。切书、切会话、变化的 source fingerprint 或明确取消使旧任务失效；异步返回不能重新显示已经关闭的浮层。

隐藏的 Reader 不上报零尺寸读位；后台时不依赖 requestAnimationFrame 一定执行。重新可见后先核对状态再采样。保持运行订阅与界面生命周期分离；用户明确“停止”才请求取消。

几何遥测仅记录必要的尺寸、状态和性能指标，不采集完整正文、问题、密钥或 RP 代码。测试截图、HAR、控制台和代理日志需要脱敏；不得把认证信息放进 URL、版本库或公开报告。

### MW4｜PDF 容器重绘、位置和资源一致性

**实施状态**：2026-09-18 本地定向验证通过；实现与限制见 [MW4 记录](performance/mobile-workspace-mw4-20260918.md)。

**前置**：MW3；包含真实 PDF 选择与标注的基线可重复。

**主要位置**：`PdfReaderPane.vue`、既有 PDF 坐标/投影辅助函数及相关测试。必要时提取私有渲染控制器，不替换证据映射算法。

**工作**：观察实际页面/阅读容器有效宽度，而不只监听 window resize。按来源身份、页面、CSS 尺寸、缩放/DPR 和渲染代际识别缓存；实际尺寸变化使旧渲染失效。仅高度变化但页面比例未变时优先更新可见页与位置，不清空所有画布。

```text
捕获页内语义锚点
→ 合并尺寸变化，分配新渲染代际
→ 取消并等待冲突任务结束，过期结果不得提交
→ 计算页面 viewport
→ 同步更新 canvas、文字层及标注投影
→ 恢复锚点
→ 恢复选区/视口采样与可见页调度
```

复用现有 PDF 坐标转换，覆盖页面 rotation；屏幕百分比不是新的证据坐标。重绘中的临时原生选区可以失效，但已经解析并冻结的范围不变；不允许用户点击错位文字层完成新的高亮。尺寸为零时等待恢复，不生成比例为零的页面。

为画布建立有界驻留与像素预算：首版候选上限为可见页及邻近页合计最多 5 张、总 backing pixels 最多 1200 万，MW0/MW4 可根据实际材料调整并记录。原始 RGBA 的估算为 `4 × backing pixels` 字节，1200 万约 4800 万字节，**不包含 GPU、副本、PDF 文档和其他内存**，不能作为总内存结论。超预算先释放远页，再降低 raster 输出倍率；CSS 几何、文字层与证据坐标保持一致。不可因降低输出倍率伪报高清。

**测试**：已渲染后旋转；对照栏展开/收起；多次连续 resize；DPR/zoom 变化；字体层和标注中心对应；取消渲染晚返回；旋转页与双栏；缩放后返回来源；滚动 30 页再回滚并核对驻留上限。静态图像拉伸不算重绘通过。

**完成判据**：可见页面的画布、文字层和标注来自同一有效几何代际；坐标与读位达到 §5；不无限累积画布；隐藏/显示后无错误选区提交。

**不做**：新增 Markdown/PDF 显式切换，或者绕过 PDF selection resolver。

### MW5｜RP 宿主、低高度展开与现场保持

**实施状态**：2026-09-18 本地定向验证通过；实现与限制见 [MW5 记录](performance/mobile-workspace-mw5-20260918.md)。

**前置**：MW3；保留当前 RP1–RP7 已完成成果，不覆盖现有未跟踪组件和测试。

**主要位置**：`AgentPresentation.vue`、`presentation.css`、`presentation-document.ts`、`presentation-bridge.js`、RightRail；现有 RP 浏览器及状态恢复测试。

**工作**：内嵌高度由内容类型及容器预算控制，长内容可内部滚动并明确提供展开。展开适配实际可用空间，标题和追问区可收敛，但关闭、来源及发送始终可达。对内容容器做响应式约束，不能只靠整个 window 的 media query。

同一 RP 在单区、对照和展开中保留版本与 browsing context；不改 `srcdoc` 重置参数。必要的 canvas/SVG 重排保持逻辑参数，不能把布局缩放保存成新的业务参数。隐藏区域不应将暂时不可见的 DOM 观察误报为语义内容被删除，也不将隐藏时的空状态覆盖已保存现场。

**iframe 内输入是专项接入点**：宿主不能读取 sandbox 内控件判断编辑状态。必要时通过既有桥增加最小、可校验的编辑焦点提示；消息必须来自当前 frame.contentWindow，绑定当前内容代际，只含编辑布尔状态等必要字段，不传问题正文。它仅辅助本地呈现，不是授权或状态真相；只有当前可见且实际获得 iframe 焦点时才生效，失焦/隐藏/切换版本后清除。键盘尺寸仍由顶层视口提供，不能为了检测焦点添加 `allow-same-origin`。

“解释当前结果”仍先保存真实现场、取得回执，再进入原 Agent 入口。保存失败保留当前内容与输入，明确提示重试；不得先发问题再假定现场成功。来源仍消费已有 opaque ref 与宿主标签。

**测试**：固定参数和步骤后在同页进行 10 次旋转/切区/展开收起；iframe load 次数不因纯布局改变增长；参数、输出与 revision 不变；iframe 内焦点和宿主输入分别开关键盘；现场保存失败/超时；来源跳转往返；后台恢复；父层裁剪和模态焦点；过期 frame 消息被拒绝。

**完成判据**：窄容器和低高度下可操作；参数与步骤保持；无绕过隔离；无法无损重建时明确阻止或提示，而不是静默丢状态。

### MW6｜多环境预览与真实触控排练

**实施状态**：2026-09-18 Windows Edge/Chromium 定向验证通过；实现与限制见 [MW6 记录](performance/mobile-workspace-mw6-20260918.md)。

**前置**：MW5 定义了宿主提供的内容边界与样式。

**主要位置**：`crates/runtime/src/presentation_preview.rs`、`crates/server/src/presentation_preview.rs`、两侧 author 接口与已有工具 schema/说明、预览集成测试。改动共享类型时由 Rust 导出；不手工维护两套协议。

**兼容合同**：当前 `width` 可选字段继续可用。拟新增可选 `viewport` 对象，明确 width、height 和 `input: mouse|touch`；请求同时给旧 width 与新 viewport 时拒绝歧义，不静默选一个。旧请求保持原默认宽 960、高 720 与鼠标环境，原宽度合法范围 240–1920 保留；新高度初始限制 160–2160 CSS px。所有数值为有界整数，错误返回真实阶段和原因。最终字段名可按现有 schema 规范调整，语义不得缩水。

预览以固定、可复现的**内容容器环境**为准，而非假装 Linux 预览浏览器就是 iPhone：

| 初始预设 | CSS 尺寸 | 输入 | 验证用途 |
| --- | --- | --- | --- |
| `narrow-content` | 320×420 | touch | 问答侧栏/窄屏内容、长标签和关键控件 |
| `short-content` | 640×240 | touch | 横屏低高度下的展开内容与操作可达性 |
| `desktop-content` | 960×720 | mouse | 保留既有桌面环境与制作能力 |

预设名称属于测试/预览环境，不进入公共书籍 schema。320×240 的组合边界作为宿主自动化补充测试，防止内容只在两个独立维度上分别通过。实际可用空间不同仍由宿主适配，不能用这三个尺寸宣称覆盖所有设备。

新内容候选按有界策略覆盖规定环境；每个环境至少执行任务的关键操作，并核对可观察结果。触控环境必须启用对应输入能力并通过真实输入路径操作，不能仅调用 DOM click 或改 User-Agent。具体以已有预览动作闭集扩展，不增加任意宿主命令、导航或文件读取能力。

反馈区分：候选执行失败、几何越界、控件不可操作、关键结果不符、取消、预算不足。环境回执与当前候选身份绑定，旧候选或其他尺寸的回执不能冒充当前通过。复用已有候选/运行记录，不另建手机内容版本库。初版固定最多三组必需环境；修正与重试沿用原运行预算及取消，不无限追加屏幕组合。

关键环境未通过时修正候选。预算耗尽可交付有依据的普通文字或保留旧版，但不能标记失败候选为适配通过。历史已交付 RP 不追溯改写或强制重新生成；使用文字/来源降级和显式修改入口。

**测试**：旧请求序列化与默认行为；非法/冲突维度；固定宽 900px 的坏候选；低处不可达的按钮；hover-only 操作；小触控目标；touch 与 mouse 事件差异；参数结果断言；多环境中途取消与进程清理；保存/交付仍按既有来源与版本闸执行。

**完成判据**：Windows/Tauri 与 Linux 现有预览宿主均有真实多环境回执和取消清理证据；实际观察可引导修正。此处的 Chromium 触控排练不写成 Safari/iPhone 实机通过。

| 恢复情形 | 必须处理 |
| --- | --- |
| 已知 turn，服务仍在运行 | 读取快照并接回原运行；不重复提交 message |
| 已知 turn，已持久完成 | 显示已完成结果并停止无意义重连 |
| 创建 POST 可能已到服务端但响应丢失 | 显示“提交结果待核对”，读取可用会话/运行信息；不能自动再次创建 |
| 服务重启、turn 不存在或无法核对 | 保留已持久历史并明确未知/中断状态；不伪装仍在生成 |
| 认证失败 | 与临时断网区分；通过现有受保护入口恢复认证，不携带密码到新 URL |
| 书/会话已由其他窗口改变 | 以权威状态核对并使旧前端回调失效；不把旧书结果装到新书 |
| 界面关闭问答 | 可隐藏内容但不请求 cancel；明确停止按钮仍沿用原取消接口 |

网络 online 信号只是核对触发，不等于服务可达。EventSource 错误不直接推断为认证问题，必要时由已有快照请求取得可区分的失败。若现有 API 无法确认一次未知提交，明确保留未知状态；新增幂等键/运行发现 API 应单列小合同，不能靠前端重发宣称解决。

补齐笔记列表与编辑、成果、画像待确认项、公式、轨迹及论文地图的入口与可用空间。正式 slot 仍用既有流程。关键操作不得只靠 hover、被裁切的侧栏标签或桌面拖拽。

**测试**：断网期间服务完成；恢复快照与 SSE 终态重复到达；后台回前台多次；POST 响应丢失；401；服务重启；切书后旧事件晚到；关闭问答不取消；10 次恢复只有一个活动订阅。真实测试产生的问题和费用要进入隔离会话记录。

## 5 发布门槛与可测指标

以下是项目的初始验收目标，不是已经实测的数据。容差变更必须说明原因并重新执行相关用例，不能只为已有失败放宽标准。

| 编号 | 必需门槛 | 测量与判定 |
| --- | --- | --- |
| G1 | 无全页横向溢出 | 标准未缩放视口下 `documentElement.scrollWidth - clientWidth <= 1px`；允许有明确边界的代码/表格/PDF 内部滚动；不能用根裁切隐藏越界后算通过 |
| G2 | 主入口与输入可操作 | 阅读、问答、返回、发送、停止、关闭覆盖层均可达；输入和按钮位于当前可见区域，不被键盘、安全区或其他层盖住；需要真机验证 |
| G3 | 连续性不依赖重建 | 10 次同页旋转/切区不重建书籍会话；已冻结引用和草稿内容相同；纯布局不增加 RP load 或内容 revision |
| G4 | Markdown 读位稳定 | DOM 稳定后保持同一 LID；存在段内锚点时保持同一规范文本位置；视口相对偏差目标不超过一行正文高度。缺少可精确映射的锚点时明确降级，不用另一段冒充 |
| G5 | 来源身份与往返正确 | 预览 0 次导航；一次打开只有一次权威来源动作；返回同一消息/RP 及原读位；未验证范围不升级为证据 |
| G6 | PDF 几何一致 | 同一几何代际；固定坐标测试中 canvas、文字层及标注对应点误差目标 ≤2 CSS px；页内锚点恢复偏差目标 ≤可见内容高度的 3%，边界 clamp 情况单独记录 |
| G7 | 原生选择和 IME 可用 | 长按、手柄、复制、中文组合输入、emoji、跨行代码通过；组合期间 0 次误发送；一次动作 1 次写入/提交 |
| G8 | RP 现场和隔离 | 参数、步骤、结果与版本保持；快照失败不发送假现场；旧/其他 iframe 消息拒绝；无新增同源或宿主权限 |
| G9 | 新 RP 有环境反馈 | MW6 规定环境实际执行关键交互；坏候选被发现；预算/取消有界；不能将预览回执等同真机证明 |
| G10 | 运行恢复无重复 | 每次用户提交至多产生本次可确认的一条运行；重连 0 次 agentRunCreate；未知提交不自动重发；终态安装和回调去重；1 个活动订阅 |
| G11 | 资源有界 | 连续阅读 30 页后 canvas 数与 backing pixels 不超过记录预算；往返旋转后监听器/渲染任务不持续增长；记录不能观察到的内存指标，不伪造浏览器内存数 |
| G12 | 桌面与部署不退化 | 既有阅读、来源、笔记、高亮、运行与 RP 回归；真实入口认证保持；线上 Web/API 版本匹配；无日常私有数据回滚 |

快速状态切换期间不要求每一动画帧都完成最终排版，但不能接受错误证据操作、不可恢复空白或焦点被永久吞掉。过渡期需要明确禁用不安全动作并保持可取消/返回。

### 6.2 连续场景

**场景 A：技术材料闭环**。在竖屏读到长段落中间，选中跨行 Rust 代码，进入提问，输入中文但暂不发送；旋转到横屏再转回，核对草稿与引用；发送一次，回看一条旧回答，打开新回答来源并核对原文，再返回原消息和原读位。

**场景 B：PDF 闭环**。在双栏论文中放大并选中跨行文字，解析后添加标注；旋转、打开/关闭对照，再拖动原生手柄选择另一段；点击来源返回同页内位置。覆盖旋转页、选择解析失败和渲染取消晚返回。

**场景 C：RP 闭环**。生成含来源与已知结果的参数实验，通过多环境排练；改变参数及步骤，展开、旋转、开启 iframe 内输入、回到问答；点击来源再返回；保存现场后发起追问；刷新后验证恢复的是已保存版本和现场，而不是声称恢复未保存操作。

**场景 D：运行恢复**。发送后关闭问答、锁屏或切应用；中断网络，让服务端继续并可能完成；恢复后读取同一 turn，核对模型运行数未增加。再注入创建响应丢失、401、服务重启与旧会话事件，不自动重发问题。

### 6.3 失败注入

| 注入 | 应发现的失败 | 必须采取的动作 |
| --- | --- | --- |
| 来源 resolve/打开返回延迟，同时切书 | 旧引用污染新书 | 丢弃过期回调并关闭无效浮层 |
| PDF 渲染 A 未完成又触发 B | 旧文字层覆盖新画布 | 取消/代际校验；只提交当前一致结果 |
| RP 现场保存超时 | 问题绑定错误参数 | 保留内容和问题，显示未发送；禁止假回执 |
| RP 固定 900px 宽、hover-only 控件 | “桌面通过、窄屏不可操作” | 预览返回真实失败并修正候选 |
| 只减小视觉视口/双指缩放 | 键盘误判、缩放反向抵消 | 不自动判输入；保留用户缩放与原偏好 |
| modal 内隐藏后继续发 selectionchange | 来自非当前表面的选区 | 拒绝采集，不更改已有冻结引用 |
| 快照终态与 SSE 重复终态竞态 | 重复完成、重复刷新/追加 | 按身份与 seq 去重，仅一次终态回调 |
| 创建运行响应被网络丢弃 | 重复模型请求 | 核对状态；未知时保持未知，不自动重发 |
| 返回应用时服务器当前书已改变 | 旧书读位覆盖新书 | 重新核对权威上下文，失效旧返回点 |
