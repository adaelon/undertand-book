# 两轮实验结论与失败复核

本页是固定检索消融记录。生产 Agent 的完整循环与实际缺陷见 [完整 Agent 评测](AGENT_EVAL.md) 和 [失败链路](agent-findings.md)。

语料为用户选择的完整 `quantification-essence`。题目、事实槽和参考锚在第一次模型调用前冻结，两轮没有改题或补答案。主表采用第二轮，初始失败不删除。

## 目前可以得出的结论

当前检索对照不支持图谱整体优于分块。第二轮在同一 `deepseek-v4-flash`、同一原文预算下，Chunk BM25 的严格成功数为 **25/28**，LID + Graph 为 **24/28**；后者平均 Token 较少，但 P95 更高。32 题是开发集，尚不能对任一方案给出普遍优越性的判断。

两组精确定位、对比、公式、来源跳转和拒绝各 **4/4**；概念任务各 **3/4**。差异集中在跨章节：Chunk **2/4**，LID **1/4**，其中 LID 的一项失败是已识别的参考锚漏判。共享 Reader 的两条笔记、高亮和阅读位置在真实进程更换后全部恢复，合计 **4/4**。

## 根据首轮失败做了什么

[首轮](results/2026-09-08-v1/report.md)要求模型在 JSON 内逐字抄写引文，输出上限 1600 Token。两组合计出现 **9 次无效 JSON**，包括公式转义及输出截断；另有正确事实因改写引文失分。

共同回答器改为：模型选择已提供的证据编号，由程序绑定实际原文，并将两组输出上限同时提高到 4096。错误编号不能绑定证据，也不能得分。变化只在评测回答器，没有修改生产 Agent 或书库。[第二轮](results/2026-09-08-v2/report.md)两组均为 **0 次无效 JSON**，公式任务均为 **4/4**。两个变量同时改变，不能把改善全部归因于引用协议。

这个改动让首轮的表观胜负反转，说明不能把格式故障混入“图谱推理更强”的结论。两轮分别保存，不合并样本，不将第二轮写成生产性能优化。

## 当前限制

- “引用支持率”是参考锚覆盖代理，不是自然语言蕴含判断。辅助引用、正确替代引文也可能不命中，不能把 `1 − 支持率` 当作幻觉率。任务成功率使用同一严格判据，同样受漏判影响。
- 两轮均为单次小样本；P95 包含真实网络和服务端波动，不是稳定 SLA。比较的是词法 Chunk 与固定 LID/图扩展控制器，不是强向量 RAG 对完整 Agent。
- 开放讲解质量、模型自主恢复记忆、用户可见的来源弹窗流程，尚未进入这张表。来源与持久化测试使用真实底层接口。

下一步先修多目标证据检索与标注等价性，再用新题复测，并分别报告开发集与新题成绩。当前可复核的项目成果是评测设计、真实引用链路和持久化闭环，尚无优于 RAG 的充分证据。
